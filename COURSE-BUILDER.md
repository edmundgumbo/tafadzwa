# Course Builder guide

Give this file, the latest Tafadzwa Academy index.html and a new transcript to Claude. Say: "Add this to the course using the Course Builder guide."

## Hard rules
1. NEVER use real client systems, names, data or logins. Use the practice world only:
   - Mama Rudo's Kitchen (Story mode): a made up kitchen in Harare.
   - Msasa Homes: a made up rental agency, with Zuri (WhatsApp leasing bot) and Mita (meter reading and billing system).
2. Labs use the learner's own free practice accounts, never a real client's.
3. Paraphrase sources. Never copy long passages. Credit the video in Sources.
4. Treat news claims in videos as the speaker's claims. Teach the method.

## How to teach (the style)
- One idea per step. Short sentences. No jargon unless it is explained the first time.
- Order inside a mission: Pip talk, animation, learn, game, try it for real, remember line.
- Mix Python, n8n and cyber freely when they connect.
- Every gated game must be solved before Next. Wrong answers get kind, useful feedback.
- Add a brain break every few missions.
- End every mission with one sentence worth remembering.

## Where things go in index.html
- STORY: missions with cards. Card types: talk, anim, learn, choice, order, fill, bug, do, remember, break.
- MODS: cyber modules (chunks, yours, drill, task, optional term).
- LABS: n8n labs (steps with h, d, code, see, q, link).
- PY: Python lessons (same step format as labs).
- ANIM: SVG animations, keyed by name. Use the f- and s- colour classes so dark mode works.
- New video: add a Sources card, then new missions or a new Season.
- MITPY, MITSEC, TOOLS, SECPLUS1-5, STORY2: more story-style seasons (same card types, plus watch and match).
- PROJ: the 3 portfolio projects (step format).
- PATH_STAGES: the single "My path" route. Anything not listed there shows as "Extra · later".

## Keep the path lean (the cream rule)
1. Only add to PATH_STAGES if it makes Ed more employable: a skill job ads ask for, a certificate step, or a portfolio project.
2. Everything else goes in as Extra.
3. Never reorder or delete existing missions: progress is saved by position. Add new ones at the end of a list.
4. Prefer a project over another quiz. Proof beats paper.

## Chunking a transcript
1. List the key ideas (max 6 per video).
2. Drop anything that is hype, ads or unverifiable.
3. Turn each idea into one mission or module.
4. Link each idea to a practice system (kitchen, Zuri or Mita).
5. Add one hands on task that can be done with free tools.
